Who can run work here

This node is the servant. Grant callers directory and tool access here. A node can hold both roles.

Execution boundaries

Pairing confirms identity without granting tools. Remote failures do not trigger local execution. Query and independently verify unknown outcomes before reconciliation; they are never replayed automatically.

Stop the node safely

Stop accepting tasks and disconnect peers. Cancelling a task does not undo effects already applied.

Saving a rule does not create a workspace. On first remote use, the system creates one under the approved root with its tool, directory, and limit template, then reuses it. Insufficient quota or denied access stops the operation; no other directory is used.
